🤖 GitHub Butler • Eidolon Edition
​GitHub Butler is a high-performance, single-file web IDE designed for autonomous repository management. Built for developers who move fast, it bridges the gap between a standard git client and an AI-driven architect.
​🌀 Features
​🧠 Resonance Protocol AI
​Powered by Gemini 2.5 Flash, the Butler doesn't just complete code—it understands your project's "Mission Statement" and "Harmonic Style."
​Neural Audit: Deep-scan fragments for security and logic flaws.
​Brainstorming: Context-aware engineering improvements.
​Ghost Author: Auto-generated technical PR descriptions and semantic commits.
​📱 Mobile-First Dev Ergonomics
​Draggable Sandbox: A live HTML/JS preview window that stays out of your way.
​Sticky UI: Navigation and file controls stay pinned to the top on small screens.
​Zero-Trust Security: Your GitHub token is stored strictly in-memory and is never persisted.
​📊 Project X-Ray
​Visualize your project's architecture instantly with AI-generated Mermaid.js flowcharts. See how your shards and fragments interact before you write a single line of code.
​☁️ Cloud Chronicle
​Synchronize your project settings, mission goals, and pinned shards across all your devices using Firebase Firestore.
​🛠️ Deployment
​This is a single-file application. To deploy:
​Create a new GitHub repository.
​Upload index.html.
​Enable GitHub Pages in the repository settings.
​Optionally, include a LICENSE and this README.md.
